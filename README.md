# Віртуальні лабораторні роботи

Матеріали Анни Сюмар для 7–9 класів. Перша робота: 8 клас, № 2 — визначення питомих теплоємностей речовин.

Завантажте index.html, style.css, app.js у корінь окремого репозиторію. GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Результати зберігаються у браузері учня. Передавання вчителю: кнопка друку, збереження PDF. Серверного збору відповідей немає.

Модель: ідеальний теплообмін, c води = 4200, міді = 400, заліза = 460, алюмінію = 920 Дж/(кг·°C). Час анімації умовний; температура округлюється до 0,01 °C.

Оновлення: для кожного досліду додано поле для самостійних розрахунків. Автоматичну перевірку та автоматичний розрахунок похибки прибрано. Поля розрахунків зберігаються у браузері й потрапляють у друкований звіт.
